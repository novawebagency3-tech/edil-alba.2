# Edilalba SNC – Demo NovaWebAgency
Sito statico (HTML/CSS/JS), nessuna dipendenza oltre ai Google Fonts.

## Pubblicazione su GitHub Pages (solo dopo autorizzazione)
1. Crea un repository e carica il contenuto di questa cartella nella root.
2. Settings → Pages → Source: branch `main`, cartella `/ (root)`.
3. Il sito sarà su `https://<utente>.github.io/<repo>/`.

## Prima di andare online
- Rimuovere `<meta name="robots" content="noindex">` e la barra demo.
- Sostituire le immagini dimostrative con foto reali; confermare servizi e testi.
- Inserire telefono/WhatsApp verificati; collegare il modulo (es. Formspree) con consenso privacy.
- Aggiungere privacy e cookie policy.
